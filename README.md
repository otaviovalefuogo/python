# Python: Dados & Desenvolvimento

## Sobre o Repositório

Este espaço centraliza os meus códigos e documenta a minha jornada de aprendizado contínuo, unindo dois mundos: o rigor analítico da **Área de Dados (Ciência de Dados)** e a lógica estrutural do **Desenvolvimento de Software (Dev / POO)**.

O objetivo é manter um histórico limpo e organizado das minhas resoluções de problemas, automações e projetos práticos, desde scripts fundamentais até análises complexas de bases de dados (como os desenvolvidos no curso da Data Science Academy).

## 📂 Como o Repositório está Organizado

Para manter a escalabilidade do projeto, a estrutura de pastas é orgânica. O repositório é alimentado continuamente e os códigos estão divididos de forma temática nas pastas.

> 💡 **Nota ** Projetos maiores e mais complexos possuem um mini `README.md` interno dentro de suas respectivas pastas, detalhando as regras de negócio e como executar aquele código específico.
